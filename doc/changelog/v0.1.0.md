# v0.1.0 — First version

[← Changelog](./README.md) · [Roadmap](../roadmap/roadmap.md)

Released: 2026-01-11 (last commit before the roadmap)

State of the project at v0.1: a single-file language with definitions, type
aliases and a few builtin types, run by an interpreter, with a REPL, a
formatter and a language server.

## Language

### Files

- One `.st` file is one program: a sequence of commands, each ending with `.`.
- A standard library ([`assets/stdlib.st`](../../assets/stdlib.st)) is embedded
  in the binary and loaded before every file, REPL session and LSP document.

### Commands

| Command | Aliases | Effect |
|---------|---------|--------|
| `Definition x [: T] := e.` | `Def` | Defines a value, with an optional type annotation |
| `Type T := U.` | `Ty` | Defines a type alias |
| `Eval e.` | `$` | Prints the value of `e` |
| `TypeOf e.` | `?:` | Prints the type of `e` |
| `Help x.` | `?` | Prints the type (or definition) of `x` and its documentation |
| `Set Flag.` / `Unset Flag.` | | Turns a debug flag on / off: `DebugLexer`, `DebugParser`, `DebugTyper` |

### Types

| Type | Aliases (stdlib) | Values |
|------|------------------|--------|
| `ℕ` | `Nat` | Natural numbers, arbitrary precision |
| `𝔹` | `Bool` | `true`, `false` |
| `Char` | | Unicode characters |

- Type aliases, unfolded during type checking; `TypeOf` prints the alias
  name (`TypeOf answer.` → `Nat`).
- Builtins are reached through internal names (`__Type_Nat__`,
  `__Constant_true__`, …) used only by the stdlib.

### Expressions

- Variables, constants, parentheses.
- Type restriction: `(e : T)`.

### Literals

- Numbers: decimal, hexadecimal `0x`, octal `0o`, binary `0b`, `_` separators;
  printed in decimal with `_` between thousands (`Eval 1000.` → `1_000`).
- Characters: `'a'`, any Unicode scalar value, escapes `\\ \" \' \n \r \t`,
  `\DDD` (decimal), `\xHH`, `\oOOO`, `\u{H…}`.

### Comments and documentation

- Comments `(* … *)`, kept by the parser (in expressions too) and by the
  formatter.
- Documentation comments `(** … *)` before a definition, shown by `Help`.

## Tooling

### CLI

`startlang <command>`:

- `run <file>`: interprets a file, exit code `0` on success, non-zero on error.
- `repl`: interactive session.
- `format <file>` with `--print`, `--diff` or `--overwrite` (default).
- `lsp`: language server on stdio.

### Errors

- Error codes and messages rendered with [ariadne](https://crates.io/crates/ariadne):
  source excerpt, labels, colors.
- Lexer, parser and typing errors; typing reports several errors at once.

### REPL

- Line-numbered prompt; input is collected until a line ends with `.`.
- History saved in `.start-history.txt` in the current directory.
- Colored output.

### Formatter

- Pretty-prints every command, keeps comments and documentation.
- `--diff` shows a line-numbered diff and fails if the file is not formatted.

### LSP

- Full document sync.
- Diagnostics on open and change: errors, and an *info* diagnostic on each
  command that prints something (`Eval`, `TypeOf`, `Help`).

## Architecture

Cargo workspace:

| Crate | Role |
|-------|------|
| `location` | `SourceId`, `Span`, `Spanned` / `Located` traits (+ derive macro) |
| `errors` | Error and message structures |
| `pp` | Pretty-printing library and themes |
| `cst` | Concrete syntax tree (keeps comments and tokens) |
| `lexer` | Tokens ([chumsky](https://crates.io/crates/chumsky)) |
| `parser` | Tokens → CST |
| `tir` | Typed intermediate representation |
| `typing` | CST → TIR |
| `vm` | Interpreter on TIR |
| `startlang` | Binary: CLI, REPL, formatter, LSP |

Tests: `trycmd` snapshots in `startlang/tests/cmd` (lexer, parser, typer,
eval, help, formatter, REPL), unit tests per crate, coverage on Codecov.

## Not in v0.1
