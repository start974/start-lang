## v0.2.0-beta.1 — Compilation phases

[Roadmap](../roadmap/v0.2-cleanup.md#v020-beta1--compilation-phases)

### Added

- Compilation phases on the whole source: lex, parse, lower, type, codegen,
  run, one after the other; a phase runs only if the one before has no
  error ([design](../design/pipeline.md)).
- `ir::sir` (surface IR, untyped AST) built by the new `lowering` pass: every
  definition gets a `DefId`, every use is resolved to it.
- `ir::lir` (low IR) built by the new `codegen` pass: a global per
  definition, an item per `Eval`; the VM runs `lir`.
- `startlang run --debug lexer,parser,lowering,typer,codegen`: each phase
  prints the representation it built ([guide](../guide/cli.md#debugging)).
- Errors say how the phase went on (*recovery*: character skipped, command
  skipped up to the next `.`, command left out) and how to fix them (*help*).

### Changed

- Crates: one crate `ir` for every representation (`token`, `pir` — was
  `cst` —, `sir`, `tir`, `lir`, `location`), one crate `pass` for every pass
  (`lexer`, `parser`, `lowering`, `typing`, `codegen`, `vm`, `stdlib`);
  `errors` and `pp` stay.
- All errors of a phase are reported, sorted by position, instead of stopping
  at the first one; a file with a lexing error reports only the lexing errors.
- Nothing runs if any phase before *run* has an error (before, the commands
  before the first error ran).
- The lexer reads the whole file once.
- The stdlib is loaded once; `startlang run`, the REPL and the LSP share the
  same chain of passes (`pass::stdlib::Stdlib`).
- REPL: an input with an error is rolled back as a whole: its definitions
  are forgotten.
- LSP: `TypeOf` / `Help` / `Eval` info only if the file has no error.
- A definition with an error, and everything that uses it, is skipped without
  further messages: only the original error is shown.
- Identifiers are shown `a@0` in debug output (was `a__0`).

### Removed

- The `Set` / `Unset` commands: the debug output is a command line option
  (`--debug`); the REPL has no debug output for now.
- The `Interpreter` trait and its three implementations.

### Fixed

- A type mismatch is shown on the expression with the wrong type, not on
  the type annotation.

## v0.2.0-beta.2 — REPL as a terminal UI

[Roadmap](../roadmap/v0.2-cleanup.md#v020-beta2--repl-as-a-terminal-ui)

### Added

- `startlang tui`: the interactive session in a full-screen terminal UI
  (`ratatui`, `ratatui-textarea`, `crossterm`; [guide](../guide/tui.md)).
  - Each input in a frame named after it (`input 3`), its own source: its
    errors point inside it (`input 3:1:6`).
  - Each command formatted, with line numbers, and under it its summary in
    a green frame (`a : N`, `3 : N`, `N`, help); an input with errors as
    typed, then its errors in a red frame.
  - The keys of a classic shell (readline); Enter runs the whole input,
    Shift+Enter (where the terminal reports it) or Alt+Enter inserts a new
    line; pasted text keeps its line breaks and does not run.
  - History: ↑ / Ctrl+P and ↓ / Ctrl+N bring back a previous input whole;
    kept between sessions in `.start-history.txt`.
  - PageUp / PageDown and the mouse wheel scroll the outputs; Ctrl+L clears
    them; F1 or Alt+H shows the keys.
- Error 103: `startlang tui` started without a terminal.

### Changed

- The colors of the theme and of the errors (`ariadne`) are drawn by the
  TUI (`ansi-to-tui`).
- `lir` holds the definitions only; the vm evaluates the `Eval` commands
  from them.

### Removed

- `startlang repl`, its line-by-line REPL and `rustyline`: replaced by
  `startlang tui`.

### Fixed

## v0.2.0-beta.3 — Cleanup

[Roadmap](../roadmap/v0.2-cleanup.md#v020-beta3--cleanup)

### Added

- `.scod` (code) and `.snbx` (sandbox) files; `FileKind` and `Source` in `location`.
- `main : u8 := …` in a `.scod`, its value is the exit code.
- Machine integers `i8` … `i64`, `u8` … `u64`; literal suffixes (`42u8`);
  literal type inferred from the annotation or the context.

### Changed

- Keywords are lowercase and short: `def`, `type`, `eval`, `typeof`, `help`.
- No final dot: a command ends where the next command keyword starts.
- Commands (`eval`, `typeof`, `help`) only in `.snbx` and the REPL.
- `assets/stdlib.st` → `assets/stdlib.scod`.
- `startlang run` runs `main` for a `.scod`, the commands for a `.snbx`.

### Removed

- `.st` files.
- Long keyword aliases (`Definition`, …).
- Operator shortcuts `$`, `?:`, `?`.
- `ℕ` / `Nat` in code (back in propositions, v0.6.0-beta.1).

### Fixed

## Known issues

- `startlang tui` (v0.2.0-beta.2):
  - long lines are not wrapped: in the outputs and in the input area, what
    does not fit the width is cut;
  - Shift+Enter is only seen by the terminals with the kitty keyboard
    protocol; elsewhere it runs the input (Alt+Enter inserts a new line);
  - F1 is kept by some terminals (GNOME Terminal): Alt+H shows the help;
  - the mouse is captured (for the wheel): Shift+drag selects text;
  - no completion (Tab) nor search in the history (Ctrl+R) yet;
  - Ctrl+W and Alt+← / Alt+→ take a punctuation mark as a word of its own.
