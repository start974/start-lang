## v0.2.0-beta.1 — Compilation phases

[Roadmap](../roadmap/v0.2-cleanup.md#v020-beta1--compilation-phases)

### Added

- `pipeline` driver: lex, parse, lower, check, type and run on the whole
  source ([design](../design/pipeline.md)).
- `startlang run --debug lexer,parser,typer`.

### Changed

- Middle-end: one crate `ir` holding every representation: `ir::pir` (parse
  IR, CST, was the `cst` crate) → `ir::sir` (surface IR, untyped AST, new,
  built by the new `lowering`) → `ir::tir` (typed IR, was the `tir` crate).
- All errors of a file are reported, sorted by position, instead of stopping
  at the first one.
- The lexer reads the whole file once.
- The file runner, the REPL, the LSP and the formatter share the driver.
- LSP: `TypeOf` / `Help` info come from typing; `Eval` is run only in a
  sandbox and only if the file has no error.
- A definition with an error, and everything that uses it, is skipped without
  further messages: only the original error is shown.
- A debug `Set` in the REPL applies to the next inputs.

### Removed

- The `Interpreter` trait and its three implementations.

### Fixed

## v0.2.0-beta.2 — Cleanup

[Roadmap](../roadmap/v0.2-cleanup.md#v020-beta2--cleanup)

### Added

- `.scod` (code) and `.snbx` (sandbox) files; `FileKind` and `Source` in `location`.
- `main : i32 := …` in a `.scod`, its value is the exit code.
- Machine integers `i8` … `i64`, `u8` … `u64`; literal suffixes (`42u8`);
  literal type inferred from the annotation or the context.

### Changed

- Keywords are lowercase and short: `def`, `type`, `eval`, `typeof`, `help`,
  `set`, `unset`.
- No final dot: a command ends where the next command keyword starts.
- Commands (`eval`, `typeof`, `help`, `set`, `unset`) only in `.snbx` and the REPL.
- `assets/stdlib.st` → `assets/stdlib.scod`.
- `startlang run` runs `main` for a `.scod`, the commands for a `.snbx`.

### Removed

- `.st` files.
- Long keyword aliases (`Definition`, …).
- Operator shortcuts `$`, `?:`, `?`.
- `ℕ` / `Nat` in code (back in propositions, v0.6.0-beta.1).
