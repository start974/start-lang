# v0.3 — Multi-file

[← Roadmap](./roadmap.md)

Projects made of several files and modules.

## v0.3.0-beta.1 — Free declaration order

Declarations can be used before they are defined.

### Tasks

Done early in [v0.2.0-beta.3](./v0.2-cleanup.md#v020-beta3--cleanup), with
the kernel IR `kir` (a graph of definitions without order):

- [x] Two-pass name resolution.
- [x] Dependency graph to compute the checking order.
- [x] Cycles are errors (recursion comes with functions and ADTs).

### Tooling

- [x] LSP go-to-definition on forward references.

### Done when

A definition can use another one defined further down.

## v0.3.0-beta.2 — Modules

Multi-file projects.

### Tasks

- [ ] `projet.toml`: project, dependencies (path, git), `[[bin]]`, extensions.
- [ ] Module layout: `A.scod`, `A.snbx` next to the `A/` directory.
- [ ] `use`: paths, groups `path.( … )`, `*`, `as`; local open in
      expressions. (The kind keyword after `use` comes with the second
      importable kind, `.synt`, in v0.5.)
- [ ] Path roots `lib`, `super`, `self`.
- [ ] Prelude; `std` as a normal dependency.
- [ ] Import cycles allowed; files of a module share their names.

### Tooling

- [ ] `startlang new`; CLI commands work on the whole project.
- [ ] Unit tests in the `.snbx` of a module; integration tests in `tests/`.
- [ ] LSP loads the whole project.
- [ ] `help` on a module (`help std.bool`): its documentation in parts
      (`.scod`, `.sprp`, `.sprf`), with the documentation of its
      definitions.

### Done when

A project with several files importing each other compiles and the LSP works on all of them.

## v0.3.0-beta.3 — Visibility

Control what a module exposes.

### Tasks

- [ ] Markers: none (local), `pub(path, …)`, `pub(lib)`, `pub(*)`, `pub`.
- [ ] Re-exports with `pub use`.
- [ ] Everything `pub` explicitly typed.

### Tooling

- [ ] LSP: visibility errors, completion only of visible names.
- [ ] Warning: `@local` documentation on a definition that is not public.

### Done when

A library exposes exactly its `pub(*)` names.
