# v0.8 — Ecosystem

[← Roadmap](./roadmap.md)

Make startlang usable with the outside world: Rust, plugins, packages and
other targets.

## v0.8.0-beta.1 — FFI with Rust

### Tasks

- [ ] FFI through the C ABI (Rust side: `extern "C"`, `#[repr(C)]`).
- [ ] JIT: Rust functions injected as symbols in the compiler process.
- [ ] AOT: objects linked with Rust crates.
- [ ] First version: scalars and pointers only (structures passed by
      pointer).

### Tooling

- [ ] Documentation of the FFI.

### Done when

A startlang program calls a Rust function, and Rust calls a startlang
function, through the JIT and the AOT.

## v0.8.0-beta.2 — Plugins

### Tasks

- [ ] Plugin API: what a plugin can hook into (CLI commands, LSP requests,
      pipeline steps).
- [ ] Plugins written in startlang, compiled by the JIT and loaded by the
      compiler.

### Tooling

- [ ] `startlang` loads the plugins declared in `projet.toml`.

### Done when

A plugin written in startlang adds a CLI command.

## v0.8.0-beta.3 — Packages

### Tasks

- [ ] Versions of dependencies and lockfile.
- [ ] Incremental compilation: cache of already-checked files and modules.
- [ ] Package registry (or later).

### Tooling

- [ ] CLI commands to add / update dependencies.

### Done when

A project with versioned dependencies is reproducible thanks to its lockfile,
and an unchanged module is not rechecked.

## v0.8.0-beta.4 — WebAssembly

### Tasks

- [ ] WebAssembly target (Cranelift), `startlang build --target wasm`.
- [ ] Runtime support for the I/O primitives on WebAssembly.

### Tooling

- [ ] Tests run on the WebAssembly target in CI.

### Done when

A startlang program runs in a WebAssembly runtime.

## v0.8.0-rc.1 — Release candidate

No new feature: the [release checklist](./roadmap.md#release-checklist), and
fixes (`rc.2`, … if needed). Unchanged, it becomes `v0.8.0`.
