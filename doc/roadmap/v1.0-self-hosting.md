# v1.0 — Stabilization and self-hosting start

[← Roadmap](./roadmap.md)

The version that allows rewriting the project in startlang.

## Tasks

- [ ] Frozen file formats (`.scod`, `.snbx`, `.synt`, `.sprp`, `.sprf`) and
      `projet.toml`: no breaking change after v1.0.
- [ ] Stable construction API of `sir` and `kir` (for external tools): no
      breaking change after v1.0.
- [ ] Stable stdlib, enough to write a compiler (strings, collections, I/O,
      error handling).
- [ ] Complete documentation of the language (`reference/grammar.md`,
      `reference/typing.md`, `reference/semantics.md`) and of the stdlib.
- [ ] Plan of the rewrite: which part of the compiler is rewritten first in
      startlang, using the Rust FFI (v0.8.0-beta.1) to mix both during the
      transition.

## Done when

Every feature needed to write the compiler is stable, and a first part of the
compiler can be written in startlang and called from the Rust code.
