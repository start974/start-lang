# v0.9 — Advanced types

[← Roadmap](./roadmap.md)

More expressive types.

## v0.9.0-beta.1 — Algebraic effects

### Tasks

- [ ] Effect declarations and effect handlers.
- [ ] Effects in function types; inference of the effects of non-`pub`
      definitions, explicit effects on `pub` ones.
- [ ] I/O, `panic` and other built-in effects expressed as algebraic
      effects; `IO` and `State` become effects, with the same user code.
- [ ] Interaction with the affine typing (continuations used at most once).

### Tooling

- [ ] LSP: hover shows the effects of an expression.

### Done when

I/O is an effect handled in `main`, and a user-defined effect (e.g. state)
can be declared and handled.

## v0.9.0-beta.2 — Rationals `ℚ`

Exact rational numbers (fractions such as `1/3`), with no rounding error.

### Tasks

- [ ] `ℚ` type: numerator and denominator kept in lowest terms, denominator
      never zero.
- [ ] Literals and constructor (`1/3` as a notation, `make_q n d`); division
      by zero handled (`panic` or a proof obligation, v0.7).
- [ ] Arithmetic, comparisons and conversions with the integer and float
      types; instances of the standard classes (equality, ordering, display).
- [ ] Relation with the `ℚ` of propositions (v0.6), as for machine integers
      and `ℕ` / `ℤ`.

### Tooling

- [ ] Formatter and LSP for `ℚ` literals.

### Done when

`1/3 + 1/6 == 1/2` is computed exactly and can be stated in a proposition.

### Open questions

- [ ] Unbounded (bignum numerator and denominator, an allocated affine type)
      or bounded (`i64` / `u64` parts, overflow like machine integers)?
      Bignums are not in the code so far (see [memory](../design/memory.md#machine-integers)).
