# v0.6 — Logic and proofs

[← Roadmap](./roadmap.md)

Propositions about the code and their proofs.

## v0.6.0-beta.1 — Logic

`.sprp` files: propositions about the code.

### Tasks

- [ ] `.sprp` file kind, `Prop`, connectives, `forall`, `exists`.
- [ ] Statements: lemmas, axioms, predicates over the code.
- [ ] Bignums `ℕ`, `ℤ` in propositions; types added to the stdlib.
- [ ] Relation between the machine integers of the code and `ℕ` / `ℤ` (a
      `u32` seen as a `ℕ` below `2^32`); requires deciding the overflow
      semantics of the primitives.

### Tooling

- [ ] LSP on statements.

### Done when

`forall n : ℕ, n + 0 = n` can be stated about the code.

## v0.6.0-beta.2 — Proofs

`.sprf` files: proofs of the logic.

### Tasks

- [ ] Decide the proof style first: tactics (possibly written with proof
      terms) or proof trees.
- [ ] `.sprf` file kind and proof checker.
- [ ] Tactics can be defined in `.synt` files.
- [ ] Basic tactics (possibly written directly with proof terms), or proof trees.
- [ ] `check` checks proofs, warns on `admit`.

### Tooling

- [ ] LSP: goals and hypotheses, view of proofs in the editor.
- [ ] Proofs in the REPL.

### Done when

A stdlib lemma is proved and checked in CI.
