# v0.5 — Dynamic grammar

[← Roadmap](./roadmap.md)

`.synt` files: user-defined notations.

## v0.5.0-beta.1 — Dynamic grammar

### Tasks

- [ ] `.synt` file kind.
- [ ] Notations (precedence, associativity) and syntax rules.
- [ ] Three-phase pipeline: notation shapes, parsing, name resolution.
- [ ] `kir` (*kernel IR*) and the `expand` phase: every notation replaced by its
      definition (`sir` → `kir`); typing runs on `kir`
      ([design](../design/pipeline.md#representations)).
- [ ] Ambiguity and conflict detection.
- [ ] Kind keyword after `use` (`use synt …`, `use code …`), now that two
      kinds are importable.
- [ ] Stdlib operators (`+`, `==`, `<`, …) defined in `.synt` on top of the
      primitives and the type classes.
- [ ] `let* p := e in body` notation for `bind`, on any monad: `IO`,
      `State σ`, … (see [syntax](../design/syntax.md#monadic-let)).

### Tooling

- [ ] Formatter and LSP support the extended grammar.

### Done when

Stdlib operators (`+`, `*`, …) are defined in `.synt`.
